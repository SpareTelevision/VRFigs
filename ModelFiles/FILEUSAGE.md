# Using Files in this folder:


### DISCLAIMER
**Hello!**
All of the files in this folder are listed under creative commons licensing, as they were built/repurposed into teaching resources. If you wish to use these in any capacity that has paid benefits, please contact the repo owner.

### HOW TO USE THESE FILES
***If you are one of ***MY STUDENTS***:
- Any model can be used in any learning capacity, including for adding as temporary models into your environment.
- any model can be *changed* visually or structurally, like a template, and added into your environment. 
- Have fun!

***If you are am ***OUTSIDE LEARNER***
- Any model can be used in any learning capacity, including for adding as temporary models into your environment.
- any model can be *changed* visually or structurally, like a template, and added into your environment. 
- Please do reach out to show what you have made with the assets and models you got from this repo! I like to keep track of projects that use these assets.


### WHAT DO I DO IF A MODEL DOESN'T WORK?
- Try deleting and re-downloading the file.
    - If that does not work, contact repo owner and you will be sent a fresher model!
- If model is missing textures, feel free to add your own and play with it! This isn't counted as a model error. however if there is a broken texture, flag it.
