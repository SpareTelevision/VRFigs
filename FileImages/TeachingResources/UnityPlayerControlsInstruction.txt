Unity Player Controls Demo Instructions

Objective

Create a simple player that can move using the keyboard.

Step 1: Create the Player

1.  Right-click in the Hierarchy.
2.  Select 3D Object → Capsule.
3.  Rename it Player.
4.  Position it above the plane.

Step 2: Add Physics

1.  Select the Player.
2.  Click Add Component.
3.  Add a Rigidbody.
4.  Under Constraints, freeze the X and Z rotations.

Step 3: Create a Script

1.  Right-click in the Project window.
2.  Select Create → C# Script.
3.  Name it PlayerMovement.
4.  Open the script.

Step 4: Replace the Script

    using UnityEngine;

    public class PlayerMovement : MonoBehaviour
    {
        public float speed = 5f;

        void Update()
        {
            float horizontal = Input.GetAxis("Horizontal");
            float vertical = Input.GetAxis("Vertical");

            Vector3 movement = new Vector3(horizontal, 0f, vertical);
            transform.Translate(movement * speed * Time.deltaTime);
        }
    }

Step 5: Attach the Script

1.  Save the script.
2.  Return to Unity.
3.  Drag the PlayerMovement script onto the Player object.

Step 6: Test

1.  Press Play.
2.  Move using WASD or the Arrow Keys.

Key Concepts

-   Scripts add behavior to GameObjects.
-   Update() runs every frame.
-   Input.GetAxis() reads keyboard input.
-   Time.deltaTime keeps movement frame-rate independent.
-   transform.Translate() moves the object.

Demonstration Script

“Now our player is interactive. The script checks for keyboard input
every frame using the Update function. When I press WASD or the arrow
keys, Unity calculates a movement direction and moves the player.
Multiplying by Time.deltaTime makes the movement consistent even if the
frame rate changes.”
